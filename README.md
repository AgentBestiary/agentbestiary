# Agent Bestiary

On-chain specimens for Binance `.ai` Agent IDs on BNB Smart Chain. 5,000 pieces, one free per agent,
then 0.0003 BNB, five per wallet at most. The art is SVG generated by the contract itself — no IPFS,
no backend, no external renderer.

## What is in here

```
contracts/
  AgentBestiary.sol        ERC-721 + ERC-2981, .ai gate, free quota, commit-reveal, on-chain SVG
  BestiaryMarket.sol       two-sided market: list / buy / bid / acceptBid, 2% fee, enumeration for the UI
  MockAgentRegistry.sol    test double for the Agent ID registry surface
test/
  bestiary.test.js         12 tests: gate, quota, price, refunds, wallet limit, reveal, market
web/
  index.html               mint + market UI (EN / ID / 中文, auto from browser language)
  app.js                   chain reads, wallet connect (injected + WalletConnect), mint, market actions
  i18n.js                  three language dictionaries
  llms.txt                 guide aimed at AI agents, including a copy-paste mint prompt
art/
  preview/                 contact sheet rendered from the contract
```

## Contracts

| what | where |
|---|---|
| NFT | deployed address is written into `web/config.js` at deploy time |
| Market | same |
| Agent ID registry (gate) | `0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F` |

Rules enforced by the contract:

- minting wallet must hold an Agent ID (`registry.balanceOf > 0`)
- first piece per wallet is free while the 1,000-piece free quota lasts
- afterwards each piece costs `price()` = 0.0003 BNB, flat
- 5 pieces per wallet, counted per minting wallet
- payment goes straight to the treasury in the same transaction; excess is refunded
- no owner, no pause, no withdraw, no upgrade path

Reveal is commit-reveal: `reveal(secret)` can be called by anyone holding the secret once
`revealBlock` has passed. If `blockhash(revealBlock)` has already expired, the seed falls back to
`keccak256(secret)` and the event reports `usedBlockhash = false` — the fallback is announced, not hidden.

## Development

```bash
npm install          # hardhat + openzeppelin
npx hardhat test     # 12 tests
npx hardhat run scripts/deploy_local.js --network localhost   # local node + seeded market
python3 -m http.server 8791 --directory web                  # UI against the local node
```

The UI reads `web/config.js`. `scripts/deploy.js` writes production addresses there, and fills the
`__NFT__` / `__MARKET__` placeholders in `web/llms.txt`.

## For agents

`web/llms.txt` is the machine-readable guide: contract addresses, `quote` semantics, selectors,
pre-flight checks and the safety rules. The same prompt is shown on the site with a copy button.
